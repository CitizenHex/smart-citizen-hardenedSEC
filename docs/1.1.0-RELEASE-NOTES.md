# Smart Citizen 1.1.0 — Editor Pane & Quality-of-Life Release

A feature release focused on more comfortable editing of long localization strings, plus a couple of small data improvements that show up in-game. No migration steps — install over the top of 1.0.x and your channel data, customizations, and backups carry forward.

## New: Editor Side-Panel

The toolbar gains an **Editor** button that toggles a dockable side-panel for editing the currently-selected row's custom value in a multi-line canvas. Built for journal entries, mission briefings, and ship descriptions that don't fit comfortably in a single table cell.

- **Drag-resizable, undockable.** Drag the title bar to undock into a free-floating window — useful on a multi-monitor setup. Position, size, and visibility persist across sessions.
- **Live sync.** The pane follows the row you select; typing in it updates the table cell and preview pane immediately.
- **Newline-aware.** Real line breaks are shown while editing and converted back to the loc-string `\n` escape on save, so values round-trip cleanly with the inline cell editor.
- **Underline / Highlight buttons.** Wrap selected text in `<EM3>` (underline) or `<EM4>` (color emphasis) without typing the tags by hand.
- **Theme-aware canvas.** The editing surface uses the lighter of the alternating-row colors so it stands apart from the dock frame.

## New: Underline / Highlight in the Inline Editor's Right-Click Menu

The Custom Value cell editor's right-click menu now offers **Underline** and **Highlight** alongside the standard Cut/Copy/Paste — same tags as the dock, available in-place for short edits.

## New: Journal Version Stamps

Every Journal entry that Smart Citizen produces or modifies — both your manual edits *and* auto-generated journal enhancements like the Mining Compendium — now ends with a version stamp when applied to the game:

> *…body text…*
>
> `[Edited with Smart Citizen v1.1.0]`

Stock CIG entries you haven't touched stay unstamped. The stamp is computed at write-time only — it never lands in your `user.ini` — and re-applying with a newer version of Smart Citizen rolls the stamp forward instead of stacking. The preview pane shows the stamp too, so you can see exactly what the in-game text will look like before applying.

## New: Radar Component Annotations

Radar components now get the same `[CLASS-S{size}-{grade}]` name-tag annotation that Shields, Power Plants, Coolers, and Quantum Drives have always had — *Cassandra [STH-S2-A]*, *FullSpec [IND-S2-A]*, etc. Visible in your loadout and hangar UI in-game.

## Fixes

- **Custom Value cells no longer erase content when entering edit mode.** Double-clicking a populated Custom Value cell now opens the editor with the existing text selected — type to overwrite, Esc to keep, click to position the caret. Previously the cell appeared to clear on double-click.
- **Generate Enhancements no longer wipes un-applied edits.** Editing a row, then running Generate Enhancements before clicking Apply, would silently discard the un-applied custom value because the post-pipeline reload rebuilt entries from disk only. Both reload paths (sync and async) now snapshot in-memory pending edits before the rebuild and re-apply them on top.

## Tutorial

The guided tour gains an *Editor pane* step. Existing 1.0.x users who completed the tour will see it auto-replay on first launch of 1.1.0.
