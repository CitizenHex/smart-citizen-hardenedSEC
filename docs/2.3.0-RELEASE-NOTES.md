# Smart Citizen 2.3.0

> ⚠️ **Heads-up if Windows blocks the installer:** Smart Citizen is not yet code-signed, and Windows 11's **Smart App Control** (SAC) blocks unsigned installers, Properties → Unblock does **not** help with SAC. To install:
>
> 1. Open **Settings → Privacy & security → Windows Security → App & browser control**.
> 2. Click **Smart App Control settings** and set it to **Off**.
> 3. Run `SmartCitizen-2.3.0-Setup.exe` and finish installation.
> 4. After install, you can return to the same screen and turn Smart App Control back on if you'd like.
>
> A code-signing certificate would remove this friction permanently. Smart Citizen is a free side project, so signing will only happen if community donations cover the recurring cost, **or** if Smart Citizen reaches enough adoption to qualify for a free certificate through the [SignPath Foundation](https://signpath.org/) open-source endorsement program. Until then: SAC-off install, SAC-on after.

## Headline

Hey Smart Citizens! 2.3.0 is the big one for reach: **four new languages**, so Smart Citizen now speaks eight. It also adds two things a lot of you have asked for, a **settings backup** you can carry to a new PC, and **export/import for your owned blueprints**.

## Four new languages

Italian, Chinese, Japanese, and German join English, French, Spanish, and Brazilian Portuguese. Pick yours from the **Language** dropdown on the Config tab, or at install time on the installer's language page.

Every language gets the whole app: the interface, the guided tour, and the in-app Help, About, Legal, and FAQ tabs. Game strings come from the community translation projects that do the real work here, credited below.

**Where we're honest with you:** the four new languages are AI translations, with no human translator yet. They're complete and they read fine, but a native speaker will spot things a machine won't. Same for the French, Spanish, and Portuguese strings added this cycle. If you speak one of these and want to improve it, we would much rather ship your words than a machine's. Translation status per language lives in `languages/TRANSLATIONS.md`, and the Discord is the place to start.

## Settings Backup

New on the Config tab: **Export Settings** and **Import Settings**.

Export bundles your whole setup into one small zip: preferences, tag configurations, your Star Citizen folder, and your custom string overrides for every channel. Import puts it back on a new PC, after a fresh portable unzip, or when you want to undo a bad afternoon of tinkering.

A few things worth knowing:

- Backups work across Smart Citizen versions, so an old zip imports into a newer build.
- Your current `user.ini` files are snapshotted before anything is written, so an import is reversible from **Restore user.ini**.
- If the backup's Star Citizen path doesn't exist on the new PC, Smart Citizen auto-detects your install instead.
- Game caches aren't included. They rebuild from your own game files, so there's no reason to ship them around.

## Blueprint Tracker

- **Export and Import Owned Blueprints.** Move your owned list between PCs or share it, in JSON or CSV. Imports only ever add, they never un-own anything, and exports from scmdb.net import cleanly too. This also answers the request to get blueprint data out of the app in a format you can feed elsewhere.
- **Ammo is its own type now.** Magazines, batteries, and salvage canisters used to land under FPS Weapon or in the Other junk drawer. They have their own filter option.
- **Scan the other channel too.** LIVE and HOTFIX share account progression, so a blueprint earned on one shows up in the other's logs. The scan now checks whichever of the two isn't your active channel, on by default. PTU, EPTU, and TECH-PREVIEW have separate progression and are never scanned.
- **Rescan all logs.** A checkbox that forces a full re-read instead of only what's new since your last scan, for when the owned list looks wrong.
- **Hover a blueprint** to see its attributes and every mission that drops it, one mission per line. Some items appear in nearly forty missions, and that used to be a single unreadable run of text.
- **Blueprint names are readable again.** Mission reward lists no longer show raw filenames like `bp_craft_nozzle_fuelgiver_grin_nozzleverysecure` where a real name belongs.

## Strings and tags

- **Ship favorites, tightened up.** The star only applies to ship and vehicle *name* rows now, since favoriting a description never did anything in game. A new **Ship/Vehicle Names Only** filter narrows the table to exactly those rows. If an older version left a stray `*` on a description, right-click offers Remove Favorite to clear it.
- **Fuel nozzles and mining lasers get name tags**, gated on the same Components > Type toggle as everything else.
- **Mining laser sizes are correct.** The size-0 heads (S0 Helix, S00 Hofstede, Lawson) were missing the size in their tag because CIG writes their size differently from every other component. Bomb racks, BEHR scopes, and the NOVA gatling were losing theirs the same way.
- **`[Owned]` tags reach the mining heads.** Hofstede and Helix could be marked owned in the tracker and still show untagged in game. They match now.
- **`[BP?]` where the payout is a roll.** Missions whose game data says the blueprint is a chance, like Rayari's collect-resources contracts at 25%, now read `[BP?]` instead of a confident `[BP]`.
- **Commodity tags start off.** The commodities Tag Builder elements now default to disabled, so a fresh install doesn't tag commodity names until you ask it to.

## Fixes and polish

- **A plain message when the launcher has your game files.** Extracting while the RSI Launcher is downloading or verifying now explains that `Data.p4k` is locked instead of showing a raw error.
- **The watermark moved to its own line** in the launcher version string, instead of crowding the build info.
- **Red buttons that wouldn't go green.** Generate Enhancements after a Simple-mode run, Apply Owned Tags after a log scan, and Save Tag Changes after a channel switch all settle correctly now.
- **Portable builds delete cleanly.** Deep folder paths no longer trip Windows' path-length limit when you send a portable folder to the Recycle Bin.
- **Help opens wide enough to read.** The Help and Test Plan panels were capped narrow by an invisible layout floor. They open readable and still drag wider.
- **Resource Signatures, split in two.** The ore-name annotation and the mission-details breakdown are independent toggles, both on by default.
- **Reputation rewards** in mission descriptions dropped a confusing leading `+`.
- **Karolinger's video guide** is credited in the About tab and the README.

## After you update

Run **Generate Enhancements** once after installing. The tag fixes above change how names are built, and the regeneration picks them up. Then **Apply to Game** as usual.
