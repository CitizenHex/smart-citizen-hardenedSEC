# Smart Citizen 1.2.0 — Faster First-Run + Upgrade Reliability

> ⚠️ **Heads-up if Windows blocks the installer:** Smart Citizen is not yet code-signed, and Windows 11's **Smart App Control** (SAC) blocks unsigned installers — Properties → Unblock does **not** help with SAC. To install:
>
> 1. Open **Settings → Privacy & security → Windows Security → App & browser control**.
> 2. Click **Smart App Control settings** and set it to **Off**.
> 3. Run `SmartCitizen-1.2.0-Setup.exe` and finish installation.
> 4. After install, you can return to the same screen and turn Smart App Control back on if you'd like.
>
> Note: A code-signing certificate would remove this friction permanently, but Smart Citizen is a free side project — signing will only happen if community donations cover the recurring cost.

## Headline: Database Conversion Performance Boost

The slowest step in Smart Citizen's first-run setup — converting CIG's DataForge database into the entity XMLs that drive every stat overlay, blueprint annotation, and crafting cross-reference — is now **roughly 5× faster**. What used to be a 5–10 minute wait is now **under 2 minutes** on most machines.

This was the single biggest source of "did it freeze?" reports during onboarding, and it's also the wait you hit every time a Star Citizen patch invalidates the cache. We swapped the bundled `unforge.exe` to an optimized build that cuts the database Save phase by ~23×; the rest of the pipeline (P4K extraction, patch application, enhancement generation) was already fast enough.

In-app messaging that used to warn "first run takes ~5–10 minutes" now reads "a few minutes" everywhere it appears.

## Fixes

- **Upgrade no longer leaves the app uninstallable.** The previous installer's silent-uninstall step would race with the new install: Inno Setup's uninstaller detaches to `%TEMP%`, returns control before the actual uninstall finishes, and its final cleanup pass would then delete the *new* uninstaller and its registry entry — leaving users with the app installed but no "Apps & Features" entry to remove it. Upgrade now displays a distinct **"Uninstalling previous version..."** step with a marquee progress bar and waits for the old uninstaller's registry-key deletion (its actual last act) before proceeding to file copy.
- **Table column headers no longer vanish until restart.** During transient layout passes (theme swap, dock toggle, splitter drag, font load) the header label could collapse to a near-zero rect and that paint would stick — restarting the app was the only way to get the labels back. The header now always paints at its base height regardless of the transient rect.
