# Smart Citizen 2.2.0

> ⚠️ **Heads-up if Windows blocks the installer:** Smart Citizen is not yet code-signed, and Windows 11's **Smart App Control** (SAC) blocks unsigned installers, Properties → Unblock does **not** help with SAC. To install:
>
> 1. Open **Settings → Privacy & security → Windows Security → App & browser control**.
> 2. Click **Smart App Control settings** and set it to **Off**.
> 3. Run `SmartCitizen-2.2.0-Setup.exe` and finish installation.
> 4. After install, you can return to the same screen and turn Smart App Control back on if you'd like.
>
> A code-signing certificate would remove this friction permanently. Smart Citizen is a free side project, so signing will only happen if community donations cover the recurring cost, **or** if Smart Citizen reaches enough adoption to qualify for a free certificate through the [SignPath Foundation](https://signpath.org/) open-source endorsement program. Until then: SAC-off install, SAC-on after.

## Headline

Hey Smart Citizens! ODW coming to you with 2.2.0, where blueprint tracking gets its own tab, more mission title options, and the app now installs in your language. 

## New in 2.2.0

### The Blueprint Tracker tab

Blueprint ownership has moved out of the Enhancements tab and into a home of its own. Available blueprints on the left, your owned set on the right, arrows to move things between them, and it all persists across restarts.

- **Flexible Search Options.** Search by name, or narrow the list by Mission, Type, Class, Size, and Grade. Armor pieces and the crossbow now sort into their proper types instead of piling up in "Other" (#217).
- **Scan Logs for Owned Blueprints.** Point it at your game install and it reads your Star Citizen logs for every "Received Blueprint" reward you've earned and marks them owned automatically. Re-runs only import what's new since the last scan, so it's cheap to run after every session (#222).
- **Apply Owned Tags** re-weaves the blue `[Owned]` tag into mission blueprint lists whenever your owned set changes, so a contract listing tells you at a glance what you still need.

### Mission Titles, redesigned

The single "shorten titles" toggle grew up into real controls (with a live preview for all of it):

- **Per-word checkboxes.** Remove "Cargo" or "Haul" outright, drop "Rank", underline Direct hauls, each independently.
- **Shorten cargo sizes** turns "Extra Small" into "XS" and friends.
- **Standardize hauling mission names** gives hauling contracts one consistent name shape.
- **New title data.** Recco Battaglia scan/mine contracts show an `[RS ####]` tag with the target ore's resource signature (#238), mission XP now names the reputation track it feeds, like `750 XP (Hauling)` (#161), and the General Tags checkboxes control each tag family on its own.

### Know before you inject

The new **Medical Consumables** category adds a plain-language effect line to the base CureLife pens, so a MedPen's description finally says what a MedPen does instead of just its lore (#224).

### Your language, from the first click

- The **installer now asks for your language up front** (English, Français, Português brasileiro, Español), and the app opens already localized. Reinstalls remember your choice (#213).
- **Every tooltip in the app is translated** (#223), and **Spanish is now fully covered**: complete interface, and for the first time the entire guided tour, thanks to Thord82's translation work.
- The Mining Compendium journal now lists each ore's **base resource signature** next to its mining locations, so "Where to Mine" answers "what will my scanner see" too.

### Smarter buttons

Generate Enhancements, Save Tag Changes, and Apply Enhancements now show **red when a change is waiting** and green when the game already matches. If you close the app with unapplied changes, it asks whether to apply first instead of letting your work sit silently on disk. The Extract button even turns red when a game patch makes your data stale.

## Fixes

- **7SA 'Concord' missing its enhancement (#210).** A duplicate-key quirk let an untagged sibling entry overwrite the enhanced one. Fixed, along with a guard so your own edits always win over that merge logic.
- **Mining laser stats showing raw markup (#221).** Mining laser and salvage tool descriptions rendered literal `<EM4>` tags and box characters in the mobiGlas. Clean text now.
- **Revenant S4 gatling showing the wrong stats (#230).** A Bengal-mounted turret variant was clobbering the Apocalypse Arms Revenant's numbers. Patched at the data level.
- **Security-threat missions listing the wrong hostiles (#186).** Handler intro contracts were leaking their spawn counts onto sibling missions. Each mission now shows only its own roster.
- **Filter row floating above every tab (#228).** The String Editor's filter controls and preview pane now live with the table instead of in the shared toolbar.
- **Deep install paths crashing extraction.** Windows' 260-character path limit broke DataForge extraction and cache cleanup on deep install paths. Every file operation now uses long-path-safe handling.
- **Progress dialogs behaving.** No more closing early at a phase boundary or sitting frozen at 100% while the cache snapshot finishes; one continuous bar, start to finish.
- **Install path quality of life.** The Browse dialog opens at your current install path, and a fresh install shows the auto-detected game folder instead of a blank field.
