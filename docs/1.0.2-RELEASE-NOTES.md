# Smart Citizen 1.0.2 — Cleanup Release

A small follow-up to 1.0.1 retiring a vestigial toolbar button and the dead code behind it. No behavior changes for the documented workflow.

## Removals

- **Removed the `Load Base File` toolbar button.** The button was a leftover from earlier versions: clicking it opened a file picker, but the worker behind it always discarded the picked file and re-loaded from configured sources instead — the same thing the app already does on startup and after `Extract from Data.p4k`. The button effectively duplicated the auto-reload path while presenting a misleading "pick a file" UI. Removed cleanly along with its handler chain (`load_files`, `_start_loading`, `_on_files_loaded`, `_on_load_error`), the unreachable `auto_load_default_files` fallback, and the legacy single-file branch in `FileLoaderWorker`. The post-extract auto-reload is unchanged and remains the canonical entry point.
- **Pruned a stale `data/contracts.ini` lookup** that referenced a path retired in 1.0.0 with the URL-based sources.

## Documentation

- `HELP.md`, `README.md`, and `ABOUT.md` now describe the flow as "extract → strings auto-load," matching what the app actually does.
- The guided tour drops the now-defunct `Load Base File` step and renumbers the remainder.
