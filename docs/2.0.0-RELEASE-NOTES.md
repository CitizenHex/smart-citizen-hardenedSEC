# Smart Citizen 2.0.0: Smart Citizen Speaks Your Language

> ⚠️ **Heads-up if Windows blocks the installer:** Smart Citizen is not yet code-signed, and Windows 11's **Smart App Control** (SAC) blocks unsigned installers — Properties → Unblock does **not** help with SAC. To install:
>
> 1. Open **Settings → Privacy & security → Windows Security → App & browser control**.
> 2. Click **Smart App Control settings** and set it to **Off**.
> 3. Run `SmartCitizen-2.0.0-Setup.exe` and finish installation.
> 4. After install, you can return to the same screen and turn Smart App Control back on if you'd like.
>
> A code-signing certificate would remove this friction permanently. Smart Citizen is a free side project — signing will only happen if community donations cover the recurring cost, **or** if Smart Citizen reaches enough adoption to qualify for a free certificate through the [SignPath Foundation](https://signpath.org/) open-source endorsement program. Until then: SAC-off install, SAC-on after.

## Headline

Hey Smart Citizens! This is the big one: **Smart Citizen now speaks more than English.** Pick **Français** or **Português (Brasil)** from the Config tab and both the app itself and your game strings switch over. That's why this release is 2.0.0 and not 1.5.0: it touches every layer of the app, from the interface chrome to the file that lands in your game folder.

Here's how it works:

- **The interface, the guided tour, the Help / About / Legal pages, and even the progress bars** are translated. Anything a translation doesn't cover yet falls back to English instead of breaking.
- **Game strings** for non-English languages come from the community translations maintained by the [Dymerz/StarCitizen-Localization](https://github.com/Dymerz/StarCitizen-Localization) project, downloaded once and cached per language. Their translators do the real work here; we deliver it with all of Smart Citizen's editing, enhancements, and backup machinery on top.
- **Your stat blocks stay English on purpose.** Enhancements are generated from game data, so a French mission briefing with an English MISSION DETAILS block is the design, not a bug.
- **Apply to Game does the right thing**: writes to the correct `Localization\<language>\` folder and sets `g_language` in `user.cfg` so the game loads it.
- **Map Language File** lets you point any language at a different `global.ini` URL, like your own fork of a community translation.

This is also where we need help. Spanish is wired up but hidden because nobody has translated the interface yet, and some French and Brazilian Portuguese strings are machine-translated placeholders until a human gets to them (every one of them is tracked in `languages/TRANSLATIONS.md`, and we would much rather ship your words than a machine's). If you can translate, come find us on the [Discord](https://discord.gg/BNzRegKZ7k).

## New features

### Multi-language support (#30)

The full list of what switching language does:

- **Language dropdown** in the Config tab, next to Channel. English, Français, Português (Brasil) at launch; languages appear automatically once their interface translation exists.
- **Per-language caching**: each language keeps its own base strings and enhancement files, so switching back is instant and your English setup is never disturbed.
- **Language-aware enhancements**: switching regenerates the enhancement INIs against that language's strings (when needed), so translated prose and English stats merge cleanly.
- **Translated guided tour**: the 18-step tutorial runs in your language.
- **Translated in-app docs**: Help, About, and Legal pages render in your language, with a note that the English version governs where it matters.
- A restart picks up the last few interface strings after a switch; the table strings reload immediately.

### More menu (#128)

The toolbar was getting crowded. Restore Backup, Clear Localization, Clear Cache, Import INI, Export INI, and Open Localization Dir now live under one **More** button, leaving the buttons you press daily front and center.

### Pick your mission details (#121)

The MISSION DETAILS block is now à la carte: show or hide each line individually (mission type, difficulty, spawns, reputation, blueprints), and the `[BP]` title tag has its own independent toggle. Your mission descriptions carry only the data you care about.

### Commodity Collection tags (#97)

Commodities used as Collection-mission objectives get their own flag alongside the crafting tag, sharing one wrapper: `[CF|Collection]` when an item is both, `[CF]` or `[Collection]` alone otherwise. Configurable in the Tag Builder like everything else.

### Your data follows you (#103)

Changing the Smart Citizen data folder now **moves** your existing overrides, backups, and caches to the new location instead of leaving them behind: merge-safe (files already in the new folder win), with the old folder cleaned up after.

### Stable executable name (#104)

The exe is now plain `SmartCitizen.exe` instead of carrying the version in its filename, so your shortcuts and taskbar pins survive updates.

## Fixes

- **Favourite prefix change no longer snaps back** on previously starred ships (#140)
- **Portable build crash on close** from non-serializable window state (#141)
- **Tutorial errored on every Next** after a replay (#138)
- **Quantum drive stats** lost QT Speed / Spool / Cooldown / Accel / Calibration in a refactor; restored
- **A space as favourite prefix** (the invisible sort-to-top trick) survives save/reload again (#100)
- **EM1/EM2 removed** from the mission-header emphasis options; they never rendered in-game (#99)
- **Type tag** now appears on components inside mission blueprint lists, not just standalone names (#101)
- **Cargo missions** show their mission details and `[BP?]` tag again (#102)
- **FPS weapons no longer get bogus tags**, and "S71" stays in weapon names instead of being stripped
- **First-run crash** on an empty table load (#110)
- **Config and Enhancements tabs no longer squish** under display scaling or small windows (#98, #145)
- **Installer no longer pre-fills stale data/cache paths** on reinstall (#120), **rejects stale SC install paths** from old registry values (#119), and **same-directory upgrades no longer run the old uninstaller**
- **Crash reports now come with a dialog** pointing at the crash log, so a frozen-build crash is no longer silent
- **Discord release announcements** carry full release notes again (the 1.4.1 and 1.4.2 posts lost them to a moved file)
- **lxml bumped** past CVE-2026-41066 (#106)

## Under the hood

- The whole language layer ships with tests, from path resolution to merge-overlay behavior; the suite now sits at 739.
- The Legal page picked up two new disclosures: the language-download network call (the only new network access in 2.0), and a translation-provenance statement. Smart Citizen still sends nothing from your machine anywhere.
- `languages/TRANSLATIONS.md` tracks exactly which strings are human-translated and which are machine placeholders awaiting a human.
