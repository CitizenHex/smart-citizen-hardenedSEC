# Smart Citizen 2.1.2

> ⚠️ **Heads-up if Windows blocks the installer:** Smart Citizen is not yet code-signed, and Windows 11's **Smart App Control** (SAC) blocks unsigned installers, Properties → Unblock does **not** help with SAC. To install:
>
> 1. Open **Settings → Privacy & security → Windows Security → App & browser control**.
> 2. Click **Smart App Control settings** and set it to **Off**.
> 3. Run `SmartCitizen-2.1.2-Setup.exe` and finish installation.
> 4. After install, you can return to the same screen and turn Smart App Control back on if you'd like.
>
> A code-signing certificate would remove this friction permanently. Smart Citizen is a free side project, so signing will only happen if community donations cover the recurring cost, **or** if Smart Citizen reaches enough adoption to qualify for a free certificate through the [SignPath Foundation](https://signpath.org/) open-source endorsement program. Until then: SAC-off install, SAC-on after.

## Headline

Hey Smart Citizens! 2.1.2 is a maintenance release, mostly bug fixes from your 2.1 reports, with one feature that changes how updates work from here on.

## New in 2.1.2

### One-click updates

Smart Citizen can now update itself. When a new version is out, it checks at launch and shows you the release notes right in the app. Click **Update Now** and it downloads the installer, Windows asks for permission once, and the app closes, updates, and reopens on the new version. No more hunting for the download link, no manual uninstall-reinstall. Your edits, backups, and settings carry over untouched (#211).

A couple of honest notes on it: Windows will still show its permission prompt (that's the same unsigned-app friction as the SAC banner above, and it goes away when we can sign), and the portable build still links you to the release page since there's no installer to run there.

### Double-click to edit

Double-click a **Current Value** cell and Smart Citizen copies it into Custom Value and drops you straight into editing, cursor ready at the start. A faster path when you want to tweak the game's existing text instead of writing from scratch. Thanks to **h0use** for this one.

## Fixes

- **Enhancements re-extracting for no reason (#209).** Launching Star Citizen made the game verify its files, which bumped a timestamp Smart Citizen was watching, so the next "Generate Enhancements" thought your DataForge cache was stale and re-ran the whole multi-minute extraction. It now checks the game file's actual size instead, which only changes on a real patch. Existing installs still work, they just re-extract once more, then settle down.
- **Fabricator tags too long to read (#208).** A commodity used in many recipes produced a name tag listing every category (`[CF|QDRV|SHLD|POWR|COOL|…]`), long enough to overrun the item name in the in-game Fabricator. The name tag now caps at four codes and collapses the rest to a `+N` count. The full list still shows in the item's description, so nothing is lost.
- **No ship-weapon filter in the blueprint tracker (#212).** Ship weapons landed in the "Other" bucket, so the Type filter couldn't isolate them. They now get their own **Ship Weapon** type.
- **Disabled "CF" label still showing up (#215).** Turning off a tag and clicking Generate Enhancements still produced the old tag, because Generate ran against the last *saved* config. It now saves your on-screen Tag Builder edits first, so what you see is what you generate.
- **"Apply Tag Changes" renamed to "Save Tag Changes" (#214).** "Apply" read like "Apply to Game" and made people think they'd already pushed changes live. The button saves your tag configs, so now it says so.
