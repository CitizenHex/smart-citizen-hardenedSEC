# Smart Citizen 1.0.0 — Production Release

Smart Citizen is a Windows desktop application for customizing Star Citizen's localization strings. Edit any in-game text — ship names, mission briefings, item descriptions, journal entries — directly in a sortable filterable table, layer in auto-generated stat enhancements that surface the data the in-game UI hides, and apply the result to your game install with a single click and an automatic backup.

This is the 1.0 production release. The app has been in continuous development since 0.1, ships with full multi-channel Star Citizen support (LIVE / PTU / EPTU / TECH-PREVIEW), a guided tutorial for new users, and a comprehensive enhancement pipeline that pulls stats and crafting data straight from your installed `Data.p4k`. The entire feature set is summarized below.

---

## String Editor (the core workflow)

The main view is a sortable, filterable table of every localization key in the game (~87,000 keys on LIVE 4.7).

- **Inline editing.** Double-click any cell in the *Custom Value* column to edit. Changes autosave to your per-channel `user.ini` immediately — no save button, no dialog.
- **Categories.** Built-in classification routes every key into Ships, Ship Items, Missions, Gear, Commodities, Journal, or Other based on its prefix.
- **Three layers of filtering.** Free-text search across all values, category dropdown, and modified/unmodified/all status — plus a per-column filter row beneath every header for fine-grained narrowing within an already-filtered view.
- **Sortable columns.** Click any header to sort, click again to reverse. The favorites column sorts starred ships to the top.
- **Live preview pane.** A rendering pane next to the toolbar shows the selected row's current value with the game's loc-string tokens translated into styled HTML (line breaks, EM3/EM4 emphasis, mission-parameter placeholders) so you see roughly how the string will appear in-game.
- **Apply to Game.** One click writes the merged result to your `global.ini`, takes a timestamped backup of the prior version first, and validates the output against the stock key set — if anything looks off, the apply rolls back and restores the backup automatically.
- **Restore Backup.** Up to five backups are kept per channel, oldest auto-pruned. One-click restore to any of them.
- **Clear Localization.** Reverts your game to vanilla text without touching your saved overrides — re-applyable any time.

## Per-Channel Star Citizen Support

Each Star Citizen channel — LIVE, PTU, EPTU, TECH-PREVIEW — is treated as a fully isolated workspace.

- **Channel switcher in the Config tab.** Switch between channels without restarting; channels with no installed `Data.p4k` are disabled with a tooltip explaining why.
- **Independent data per channel.** Each channel has its own `user.ini`, source cache, DataForge extraction, backups, and enhancement INIs under `Documents\Smart Citizen\<channel>\`.
- **Channel-aware status bar.** A persistent indicator shows the active channel, and the Star Citizen version string includes the channel suffix.
- **Automatic migration** from the older single-channel layout. Existing users are moved into the per-channel layout transparently on first launch.

## Auto-Generated Enhancements

Smart Citizen extracts entity data straight from your installed `Data.p4k` and overlays useful stats and cross-references on top of the stock localization. Each enhancement category is independently togglable in the Enhancements tab.

- **Ship descriptions** get SCM speed, hydrogen and quantum fuel, cargo capacity, full weapon loadout, and armor damage multipliers (physical / energy / distortion / thermal).
- **Ship weapons** get DPS, fire rate, range, and per-shot damage from size 1 through capital. Missile and bomb names are tagged with size and tracking type — *Arrester III [S3-IR]*, *500SCB Cluster [S5]*.
- **Ship components** (shields, coolers, power plants, quantum drives, radars) get HP, regen, draw, cooling rate, and other component-specific stats appended to their descriptions.
- **FPS weapons** get DPS, fire rate, range, and damage values.
- **Mission contracts** are annotated with `[BP]` (always rewards a blueprint) and `[BP?]` (only some variants do) tags in their titles, and gain three structured blocks in their descriptions: *MISSION DETAILS* (spawn counts, difficulty, XP, faction flags), *POTENTIAL BLUEPRINTS* (item pools split by system where they vary), and *ITEM REWARDS* (guaranteed item payouts).
- **Journal entries** for harvestables and minerals gain location and crafting cross-references.
- **Commodities used in crafting** get a `[CF]` name tag and a *BLUEPRINT DATA* section listing every blueprint that uses them — turn over a piece of gold ore, see every weapon and component it's an input to.

A declarative patch system applies fixes to known CIG-side data bugs at extraction time — for example, the Jorrit Dossier P2M4 mismatch (STARC-176797) where the game points at the wrong loc-key for a contract description. Patches mirror the DataForge layout and are reapplied idempotently on every regen, so fixes stay in place across game updates without waiting on CIG.

## DataForge Integration

The "Extract from Data.p4k" button drives a four-step pipeline that runs in the background and reports progress through a single determinate progress bar:

1. **Unpack** Game2.dcb from the installed `Data.p4k` using bundled `unp4k.exe`.
2. **Convert** the DataForge database to entity XMLs using bundled `unforge.exe`.
3. **Apply patches** from the `patches/` directory to fix upstream data bugs.
4. **Generate enhancements** — ships, components, ship weapons, FPS weapons, missions, journal, and commodity crafting — and reload the table.

Smart Citizen auto-prompts when the cached extraction is stale relative to the game's `Data.p4k` (typical trigger: a game patch landed since the last extraction). All steps run off the UI thread; the editor stays responsive throughout.

## Import / Export

- **Import INI.** Fold an external `.ini` from another tool, a community pack, or a previous Smart Citizen backup into your overrides. A conflict-resolution dialog lets you decide per key whether to keep your current value, take the imported one, append, prepend, or write a custom merge.
- **Multi-source merge hierarchy.** Localization sources (stock, contracts, components, ships, commodities, gear, user) merge in a configurable drag-and-drop order, with user overrides always applied last so your edits never get overwritten by source updates.

## Favorite Ships

Star a ship in the table and a configurable prefix (default `*`) is prepended to its name, sorting your starred ships to the top of the in-game ASOP terminal. Prefix character is editable from the Enhancements tab.

## Themes

Pick from four built-in themes in the Config tab:

- **SCLE** — deep-navy cyber theme inspired by Star Citizen's mobiGlas UI (default)
- **Light** — classic light UI
- **Dark** — classic dark UI
- **ODW** — Osiris DevWorks signature, navy charcoal with antique gold

## Guided Tutorial

A coach-mark tour walks new users through the core workflow — extract, load, edit, preview, apply, enhancements, help — with on-screen callouts pointing at each control. The tour runs automatically on the first launch of each new version, and the Tutorial button on the toolbar replays it on demand at any time.

## In-App Log Viewer

The Log tab shows the application log in real time with level filtering, auto-scroll, and an Export button for attaching to bug reports. Helpful for diagnosing extraction errors, source download issues, or anything else that misbehaves silently.

## Auto-Update Notifier

Smart Citizen checks GitHub Releases for a newer installer every six hours (well within the unauthenticated rate limit) and surfaces a non-blocking notification when an update is available. Clicking through opens the release page; you stay in control of when (and whether) to upgrade.

## Installer

The installer is a single `.exe` that handles fresh installs and in-place upgrades. Per-user data — `user.ini`, `backups/`, and your customizations — survives both upgrades and uninstalls so a reinstall picks up exactly where you left off. Only the regeneratable cache is removed on uninstall.

## Keyboard Shortcuts

- **Ctrl + Shift + C** — Copy the currently filtered rows to clipboard in `key=value` format. Useful for sharing a custom set with the community or for moving a partial config between channels.

## Discord Community

Bugs, feature requests, and feature voting all go through the dedicated `#smart-citizen` channel on the Osiris DevWorks Discord (server invite: https://discord.gg/BNzRegKZ7k). Reactions and polls drive prioritization for future releases — the squeakiest ideas are the ones that land first.

## What's Next

Post-1.0 priorities include localization for languages other than English, possible FPS armor stat enhancements, and continued tracking of CIG's evolving DataForge schema as new game features land. The roadmap is community-driven via Discord — vote for what you want next.
