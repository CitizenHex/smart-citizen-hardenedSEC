# SC Localization Editor

## About This Project

**SC Localization Editor** is a comprehensive tool for Star Citizen players to customize their game's localization strings. Edit global.ini directly with an intuitive interface, and apply your changes safely with automatic backups.

SC Localization Editor is developed by **Osiris DevWorks**, a one-man development studio dedicated to making tools that support gamers.

## The Osiris DevWorks Promise

All Osiris DevWorks tools will be either **completely free** or have a **free tier**. We believe in creating value for the gaming community without paywalls or mandatory subscriptions.

## Key Features

- **Load & Edit**: Load global.ini from your Star Citizen installation and customize strings
- **Smart Filtering**: Search, filter by category or status to find strings easily
- **Safe Application**: Automatic backups before applying changes to your game
- **Restore Backups**: Keep up to 5 backup versions to revert changes anytime
- **Intuitive UI**: Clean interface with table view, filters, and in-line editing
