# Smart Citizen 1.0.1 — Hotfix Release

A small follow-up to 1.0.0 covering a first-run UX fix, an uninstaller cleanup fix, the new `HOTFIX` Star Citizen channel, and a final pass on the retired URL-source pruner.

## Fixes

- **First-run tutorial no longer collides with startup prompts.** Source-sync, app-update check, and any modal pop-ups (P4K extraction prompt, "new version available" dialog, enhancements pipeline prompt) now wait until the guided tour finishes (or is skipped) before firing. Previously, on a fresh install the tutorial would launch on top of, or get interrupted by, those modal dialogs.
- **Uninstaller now reliably removes per-channel cache directories.** The cleanup helper now consults the app's `user_data_dir` registry override (so installs that pointed away from a OneDrive-synced Documents folder are handled correctly), enumerates every channel including the new `HOTFIX`, and logs both the path it tried and whether the directory still exists afterwards. Silent failures from locked files now surface in the install log.
- **`Gear (0)` no longer lingers in the Merge Preview after upgrading.** The retired-URL-source pruner introduced in 1.0.0 missed the `gear` source — it has been added to the retired list, the migration marker has been bumped so 1.0.0 users get the cleanup, and the pruner now also handles the case where a retired source name was registered in the merge hierarchy without a per-source path entry.

## New

- **`HOTFIX` channel support.** The Config tab's channel dropdown now offers `LIVE / PTU / EPTU / HOTFIX / TECH-PREVIEW`. Each channel keeps its own isolated `user.ini`, cache, backups, DataForge extraction, and enhancement INIs under `Documents\Smart Citizen\<channel>\`, just like the existing channels.
