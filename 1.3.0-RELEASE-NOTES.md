# Smart Citizen 1.3.0 — Mission Intel + Portable Build + Apache 2.0

> ⚠️ **Heads-up if Windows blocks the installer:** Smart Citizen is not yet code-signed, and Windows 11's **Smart App Control** (SAC) blocks unsigned installers — Properties → Unblock does **not** help with SAC. To install:
>
> 1. Open **Settings → Privacy & security → Windows Security → App & browser control**.
> 2. Click **Smart App Control settings** and set it to **Off**.
> 3. Run `SmartCitizen-1.3.0-Setup.exe` and finish installation.
> 4. After install, you can return to the same screen and turn Smart App Control back on if you'd like.
>
> Note: A code-signing certificate would remove this friction permanently, but Smart Citizen is a free side project — signing will only happen if community donations cover the recurring cost.

## Headline: Two new mission-detail lines and a portable build

The MISSION DETAILS block on every contract now tells you **what loadout to bring** and **whether the location has hostile turrets** before you accept — two pieces of intel that previously lived only in CIG's loc-key naming and the spawn XML. And for players who want to run Smart Citizen off a USB stick or without touching the registry, there's now a **portable build** alongside the standard installer.

## What's new

### Mission descriptions get *Engagement Type* and *Turrets*

Pulled from CIG's own DataForge data — both fields are derived rather than authored, so they stay accurate across patches:

```
<EM3>MISSION DETAILS</EM3>
<EM4>Engagement Type:</EM4> FPS & Ship          ← new
<EM4>Mission Type:</EM4> Chain
<EM4>Difficulty (1-7):</EM4> Combat 4/7 | Complexity 4/7 | Risk 3/7 | Knowledge 3/7
<EM4>Enemies:</EM4> 12
<EM4>Non-hostiles:</EM4> 4
<EM4>Turrets:</EM4> 5 (hostile)                 ← new
<EM4>Reputation XP:</EM4> +10
```

- **Engagement Type** classifies as `FPS`, `Ship`, or `FPS & Ship` based on CIG's loc-key naming convention (`_FPS_`, `UGF_`, `OnFoot_`, `FPSMine`) plus cargo / salvage / freight tokens that signal the mission needs a ship for transport on top of the on-foot phase.
- **Turrets** sums the spawn-data turret count and surfaces the explicit hostility flag when CIG sets one (defaults to "hostile" for spawned turrets, which matches every observed case in the live 4.7 dataset).

### Standalone (portable) build

A new `--portable` build flavor packages Smart Citizen into a self-contained zip you can extract anywhere:

- All settings, cache, backups, and `user.ini` live in a `data/` folder next to the .exe — **zero registry footprint**.
- USB-stick-friendly. Run from a network share. Drop one folder, get a fresh independent install.
- **`SmartCitizen-Portable-v1.3.0.zip`** is attached to this release alongside the regular installer.

### "Enhanced" status badge

The Status column now distinguishes between user edits and Smart Citizen's auto-generated content:

- **Modified** (green) — you've set a Custom Value
- **Enhanced** (blue) — produced by Smart Citizen's enhancements pipeline (ship stats, mission rewards, `[BP]` tags, etc.)
- **Unmodified** (grey) — stock base.ini text, unchanged
- **New** (orange) — key only exists in user.ini / enhancements

Filter by "Enhanced" to see at-a-glance what the app generated; filter by "Modified" to see only your own edits.

### Export Loc-Pack toolbar button

New **Export** button on the toolbar that packages the currently-applied `global.ini` into a zip for sharing — drop on Discord, your org's site, anywhere. Recipients drop the file straight into their game's localization directory; no Smart Citizen install required on their side. Default filename is channel-aware (`SmartCitizen-LocPack-LIVE-20260509.zip`) since LIVE / PTU stock keys diverge.

### Tutorial Skip is now permanent

Clicking **Skip** on the guided tour now persists across versions — power users who skip deliberately don't get re-prompted on every release. The Tutorial button on the toolbar is still there for on-demand replay.

## Fixes

- **Toolbar buttons no longer drift down ~40px when switching to Config or Enhancements tabs.** The preview pane on the right was greedy with vertical space when the active tab had slack to give, inflating the entire toolbar row. Cap-and-policy fix keeps the row a constant height across all tabs.
- **The preview pane is back to a usable height (~120px).** Big enough for 5–6 lines of rendered HTML; long mission journals overflow into its built-in scrollbar.

## Behind the scenes

- **Apache License 2.0** + a `NOTICE` file with attribution for bundled `unp4k` / `unforge` (MIT) and the Star Citizen / CIG trademark notice. Both are next to the .exe in the install dir; the in-app About panel now references them.
- **Major refactor**: extracted ~600 lines of testable helpers and worker threads out of the monolithic main window. Result: ~30% smaller main window file, +164 new automated tests (115 → 279), zero behavior regressions.
- **CI/CD pipeline**: every PR now runs through GitHub Actions on a Windows runner (tests + build verification). Releases auto-fire on merge to main — installer, portable zip, and Discord notification all happen without manual intervention.
